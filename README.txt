INVITATION STUDIO - hosting guide

Is folder mein sirf index.html hai. Ye ek akeli file hai (music aur sab kuch andar hai), koi build ya server nahi chahiye.

GITHUB PAGES
1. github.com par New repository banao (jaise invitation-studio), Public rakho.
2. "uploading an existing file" par click karo aur index.html drag & drop karo, Commit karo.
3. Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root) > Save.
4. 1-2 minute baad link milega: https://USERNAME.github.io/invitation-studio/

CLOUDFLARE PAGES
1. dash.cloudflare.com > Workers & Pages > Create > Pages > "Upload assets".
2. Project name likho, is zip ko extract karke folder (ya sirf index.html) upload karo > Deploy.
3. Link milega: https://PROJECT.pages.dev

NOTES
- File ka naam index.html hi rehne do.
- Hosting ke baad "Download File" aur "Copy Share Link" dono kaam karte hain.
- Share link customer ka data link mein rakhta hai, to customer ko wahi studio link ke saath #i=... wala link do.
- Default nasheed copyrighted hai (Muhammad Al Muqit). Customers ko bechne se pehle permission lo, ya soft tune / customer ki apni audio use karo.
- Page 5.6 MB ka hai, pehli baar khulne mein thora time lag sakta hai.
